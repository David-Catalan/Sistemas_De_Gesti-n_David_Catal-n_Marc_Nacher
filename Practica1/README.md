# SGE UT1 - Actividad 1: Selección de un ERP

Matrices de decisión configurables (HTML + CSS + JavaScript) que comparan **Odoo Enterprise, Holded y Microsoft Dynamics 365 Business Central** para dos empresas, cada una con su propia matriz:

1. Supermercado La Plaza
2. Reformas Levante

## Cómo verla

Abre `index.html` en el navegador (doble clic). No necesita servidor. Se pueden cambiar las valoraciones (0 a 3) y los pesos de cada criterio; los totales se recalculan solos con `(valoración × peso) / 3`.

## Estructura

```
actividad01-erp/
├── index.html                 Página con las dos matrices
├── css/style.css              Estilos
├── js/datos.js                Criterios, pesos, notas, TCO, justificación y decisión
├── js/matriz.js               Cálculo y pintado de la página
├── capturas/                  Capturas de las dos matrices
├── docs/documento.pdf         Documento: conclusiones y 2 puntos justificados con fuentes
├── docs/documento.html        Mismo documento en HTML
├── docs/justificacion.md      Informe ampliado (TCO, herramientas, dudas sobre la IA)
└── README.md
```
